# 萬鈞伯裘書院 2026–2027 校曆

依《校務手冊26-27-007》把 2026–2027 年度校曆放到月曆上，並可在任何一天填寫個人工作安排。官方校曆寫在網站程式裡；個人備註可選擇用同步碼雲端同步。

官方 PDF 放在 `public/mkpc-calendar-2026-2027.pdf`。

## 功能

- 顯示學校假期、學校自決假期、教師發展日、考試／統測、學習活動、交流團／出團、會議與機構活動
- 學年由 2026 年 9 月至 2027 年 8 月，全年上課日數 191 天
- 點選日期可對照校務，並新增自己的會議、任務或備註
- 月曆與年曆檢視、搜尋、匯出／匯入 JSON

## 在手機或其他電腦查看

正式網站：**https://2027-work-planner.vercel.app**

假期、考試、交流團等官方校曆寫在網站程式裡。更新並部署到這個網址之後，所有裝置重新整理就會看到同一份。不要把 Cursor 預覽或 `127.0.0.1` 當正式網址。

你自己寫的工作安排預設存在各部裝置的瀏覽器。要自動同步：在網站右上「其他裝置」設定同一組同步碼。正式網站需在 Vercel 設定 `SYNC_TOKEN`（GitHub classic token，勾選 **gist**）或連接 KV，然後重新部署。仍可用一次性同步連結或匯出／匯入 JSON。

## 本機執行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的網址（預設為 `http://localhost:3000`）。

建置正式版：

```bash
npm run build
npm start
```

## 資料存放

個人安排寫入瀏覽器 `localStorage`，鍵名為 `work-calendar-2026-2027`。若已啟用同步碼，加密後的備份會存到雲端（伺服器看不到明文）。校曆活動寫在程式裡，不會被清除或匯入覆蓋。
