# 萬鈞伯裘書院 2026–2027 校曆

依《校務手冊26-27-007》把 2026–2027 年度校曆放到月曆上，並可在任何一天填寫個人工作安排。個人資料只存在瀏覽器本機。

官方 PDF 放在 `public/mkpc-calendar-2026-2027.pdf`。

## 功能

- 顯示學校假期、學校自決假期、教師發展日、考試／統測、學習活動、會議與機構活動
- 學年由 2026 年 9 月至 2027 年 8 月，全年上課日數 191 天
- 點選日期可對照校務，並新增自己的會議、任務或備註
- 月曆與年曆檢視、搜尋、匯出／匯入 JSON

## 在手機或其他電腦查看

這個網站要放到互聯網，其他裝置才能打開。最簡單是免費部署到 Vercel：

1. 把專案放到 GitHub（在 Cursor 可建立倉庫）。
2. 前往 [vercel.com/new](https://vercel.com/new)，用 GitHub 登入並匯入這個專案。
3. 部署完成後會得到網址，例如 `https://你的專案.vercel.app`。
4. 手機、平板、電腦用瀏覽器打開同一個網址即可看到官方校曆。
5. 你自己寫的工作安排存在各部裝置的瀏覽器。可用網站上的「其他裝置」複製同步連結，或用「匯出 / 匯入」JSON。

## 本機執行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的網址（預設為 `http://localhost:3000`）。

建置正式版：

```bash
npm run build
npm start
```

## 資料存放

個人安排寫入瀏覽器 `localStorage`，鍵名為 `work-calendar-2026-2027`。校曆活動寫在程式裡，不會被清除或匯入覆蓋。
