# 2026–2027 工作月曆

在 2026 與 2027 年的月曆上，點選任何一天填寫工作安排。資料只存在瀏覽器本機，不會上傳伺服器。

## 功能

- 月曆與年曆兩種檢視，涵蓋 2026 年 1 月到 2027 年 12 月
- 每天可新增多則安排：標題、類型、時間、地點、備註
- 類型包含會議、任務、出差、私人、其他
- 搜尋標題、地點或備註
- 匯出／匯入 JSON 備份
- 回到今天、本月清單與接下來的行程

## 本機執行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的網址（預設為 `http://localhost:3000`）。

建置正式版：

```bash
npm run build
npm start
```

## 資料存放

安排會寫入瀏覽器 `localStorage`，鍵名為 `work-calendar-2026-2027`。換裝置或清除網站資料後，請用「匯出」的 JSON 檔再「匯入」。
